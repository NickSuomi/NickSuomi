# Building tools that explain themselves

I build developer tools and operator-facing systems around explicit contracts, typed failures, and inspectable evidence. I prefer deterministic cores, narrow side-effect boundaries, and human review where actions become consequential.

## Selected work

- [Morpheus](https://github.com/NickSuomi/morpheus) — agent operations with isolated runs, an auditable ledger, and a human-reviewed merge flow.
- [Spritefoundry](https://github.com/NickSuomi/spritefoundry) — deterministic SVG tooling with typed artifacts and CLI, Vite, and Vue integrations.
- [State Bridge](https://github.com/NickSuomi/state-bridge) — a permission-aware browser-state debugging tool with allowlist and end-to-end coverage.
